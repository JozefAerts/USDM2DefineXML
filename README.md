# USDM2DefineXML
Proof-of-Concept (POC) Java program to demonstrate the automated generation of prototype CDISC define.xml files starting from a study design containing CDISC "Biomedical Concepts" and "SDTM Dataset Specializations", using the CDISC-Library API.
In order to run the software, you will need a CDISC-Library API key, which you need to copy into the "properties.dat" file.
